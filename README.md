## Featured project

### [Procure-to-pay analytics: SAP → Microsoft Fabric](https://github.com/bigmike2307/sap-p2p-fabric-analytics)

[![pipeline-tests](https://github.com/bigmike2307/sap-p2p-fabric-analytics/actions/workflows/ci.yml/badge.svg)](https://github.com/bigmike2307/sap-p2p-fabric-analytics/actions/workflows/ci.yml)

End-to-end P2P analytics on realistic synthetic SAP data: CDS extraction views with change data capture, a PySpark medallion lakehouse, a star schema with 24 KPIs, and a 54-check data quality gate that runs in CI on every push.

| Finding | What it means |
|---|---|
| **£304k** | duplicate invoices paid, missed by SAP's exact-match check |
| **8 pts** | of OTIF lost to short deliveries |
| **£434k** | GR/IR older than 90 days, ready for the year-end clean-up |
| **£1.05m** | committed only after the invoice arrived |
